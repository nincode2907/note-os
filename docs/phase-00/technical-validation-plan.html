Baseline kiến trúc

Các lựa chọn định hướng cho spike; engine đồng bộ offline vẫn để mở cho tới khi có kết quả benchmark.

⌘

Ứng dụng

Monorepo pnpm · Web với Next.js, React, Tiptap · iPhone với Expo và React Native.

▤

Server

Laravel 12, PHP 8.4, MySQL và Redis; Web, backend, database, worker chạy qua Docker Compose.

◈

Dữ liệu

ProseMirror/Tiptap JSON có schema version là nguồn chuẩn; Markdown chỉ là bản xuất dẫn xuất.

Luồng kiểm chứng

Mỗi quyết định phải dẫn tới phần mềm chạy thật, bằng chứng có thể truy xuất và trạng thái trung thực.

Sáu spike

Chi tiết kịch bản, các trường hợp bắt buộc và tiêu chí đánh giá nằm trong brief Markdown đầy đủ.

A

Âm thanh và phục hồi

Đánh giá expo-audio trên iPhone: background, pause/resume, interruption, phân đoạn, manifest, restart và phát lại.

Cần thiết bị thật để PASS native
B

Editor và document chuẩn

So sánh Tiptap Web, nhập nhanh native, Markdown editor và rich editor; kiểm tra Việt/Telex, Nhật IME và chuyển đổi JSON.

Không mất node hoặc thuộc tính được hỗ trợ
C

So sánh sync offline

PowerSync + MySQL, WatermelonDB với adapter thật, và custom Delta Sync; kiểm tra conflict, retry, crash, delete và migration.

Quyết định kiến trúc quan trọng nhất
D

Docker, lưu trữ và tìm kiếm

Stack cô lập, persistence, healthcheck, backup/restore và tìm kiếm tối thiểu 5.000 note đa ngôn ngữ.

Đo recall, precision, p50 và p95
E

Riêng tư và hợp đồng AI

Xác minh ranh giới provider thực tế cho DEVICE_ONLY, PRIVATE_SERVER, CLOUD_ALLOWED và hành vi fail-closed.

Không suy đoán API hoặc chính sách
F

Độ bền và khôi phục

Truy vết capture → local commit → sync → server commit → backup → restore, gồm media và dữ liệu chưa đồng bộ.

Nêu rõ dữ liệu chưa có trong backup

Ranh giới bắt buộc

Các giới hạn này áp dụng trong toàn Phase 00.

Điều kiện vận hành

  • Chạy backend, database, Web và worker bằng Docker Compose.
  • Test có thể phá dữ liệu phải dùng database Docker cô lập; không reset volume dữ liệu thật.
  • Không thay đổi project/container của MemoryOS, AI Gateway hay ứng dụng khác.

Riêng tư và báo cáo trung thực

  • Không dùng AI cloud trả phí hoặc gửi dữ liệu cá nhân ra ngoài.
  • Không tự tạo tài khoản hay dùng thông tin xác thực chưa được cấp.
  • Thiếu iPhone thật, signing hoặc quyền truy cập: ghi BLOCKED và bằng chứng còn thiếu.
