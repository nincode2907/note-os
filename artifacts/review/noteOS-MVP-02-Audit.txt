# noteOS — APPROVED: MVP-02 Local Audio Recording & Playback

**Lead Architect:** ChatGPT  
**Implementer:** Codex  
**Status:** APPROVED — MVP-02 ONLY  
**Execution:** Autonomous within scope

MVP-01.2 đã được Lead Architect chấp thuận ở mức single-device Web MVP, với các giới hạn durability đã công bố.

## Mission

Build usable, local-first audio recording and playback integrated into noteOS Web notes.

Users should be able to:
- Record microphone audio.
- Stop and save a recording.
- Replay it after page reload.
- Associate recordings with notes.
- Rename and remove recordings.
- Export their recordings.
- Understand whether recording is active, saved, failed, or recoverable.

No server or cloud provider is required.

## 1. Preflight

Read AGENTS.md, existing architecture documents, MVP-01.2 report, document engine and IndexedDB repository.

Preserve the accepted autosave coordinator, canonical JSON v1, revision checks, recovery behavior and privacy guarantees.

Inspect the current Git branch, status and remote.

Do not modify unrelated Phase 00 work.

## 2. Audio Storage Architecture

Implement a versioned local media storage layer using IndexedDB.

Keep binary audio separate from canonical ProseMirror JSON, associated through stable note and recording IDs.

Choose a schema and migration strategy that preserves all existing MVP-01 notes without rewriting or resetting them.

Use transactions and explicit recording states where appropriate.

Consider durability during long recordings: do not rely solely on keeping an entire long meeting recording in RAM until Stop.

Evaluate MediaRecorder timeslice/chunk persistence and implement a reasonable bounded approach, with clearly documented limitations.

A recording interrupted by page reload or process termination must never be falsely labeled complete. Preserve recoverable chunks where feasible.

Do not promise background recording or crash-proof durability.

## 3. Recording Experience

Use browser microphone APIs supported by the target browser.

Handle:
- Permission denied.
- No microphone.
- Unsupported browser/API.
- Start/Stop.
- Pause/Resume when supported.
- Microphone interruption or track ending.
- Partial recording and write failure.
- Storage quota problems.
- Recording timer.
- Preventing accidental duplicate sessions.

Show clear recording and save status.

Do not request microphone permission until the user intentionally starts recording.

Do not send recordings to any external service.

## 4. Playback and Management

Within a note, provide:
- Recording list.
- Duration and creation time.
- Play/Pause and seek where supported.
- Rename.
- Download original audio.
- Delete with clear confirmation.
- Reopen playback after refresh.

Choose MIME/codec based on runtime capability detection, not assumed extension support.

Release object URLs, media tracks and other resources correctly.

Avoid automatically deleting a recording merely because the parent note is archived or trashed.

## 5. Backup and Data Safety

Audit the existing JSON backup contract before implementation.

The current MVP-01 backup contains notes only. Adding audio must not silently create the impression that a notes-only backup protects recordings.

Provide an explicit export path for audio and accurately state its coverage.

If implementing a combined versioned backup bundle is feasible and safe, preserve backward compatibility with existing v1 backups and fully validate import before mutation.

Otherwise keep backup scopes clearly separated and document what users must export.

Never silently discard existing notes or media.

Do not implement sync.

## 6. Tests and Runtime Acceptance

Implement targeted automated tests and actual browser scenarios covering:

- Permission denied and unsupported API.
- Recording start/stop.
- Supported pause/resume.
- Persist/reload/playback.
- Recording linked to correct note.
- Audio export.
- Delete/confirmation.
- Storage write failure.
- Interrupted recording and recoverable state.
- Multiple recordings and note lifecycle.
- Existing MVP-01 regression suite.

Use synthetic audio or controlled browser fixtures for automation.

At least one real microphone test, if available and explicitly permitted, should be distinguished from fake-media test evidence.

Run typecheck, build and source checks.

Keep test claims scoped to actually observed behavior.

## 7. UI and UI Lens

Integrate audio recording into the existing noteOS editor without making the interface unnecessarily complex.

Capture relevant desktop/mobile states using UI Lens:
- Recording idle.
- Recording active.
- Saved recording.
- Playback.
- Permission/error state.
- Partial/recovery state where supported.

Do not capture private conversations or user recordings.

Preserve existing Web note flows and responsive layout.

## 8. Resource Policy

Prioritize shipping the feature.

If RAM is insufficient, report measured host RAM, Docker/WSL allocation and the amount needed, and ask the user to increase allocation when appropriate.

Do not automatically redesign the system or stop unrelated services.

Do not alter Docker settings without approval.

# Independent Review Brief — noteOS MVP-02 Local Audio

Review the implementation and evidence in this package against the approved MVP-02 brief. Focus on data safety and hidden lifecycle failures. Do not infer broader compatibility from the tested Chromium environment.

## Review questions

1. **Recording lifecycle:** Can start, pause/resume, stop, duplicate-session prevention, tab navigation, recorder errors and unmount/reload create an invalid state or lose already committed chunks?
2. **Partial durability:** Is the `recording`/`paused`/`complete`/`interrupted`/`failed` state machine truthful? Assess per-tab recovery, the two-minute recording staleness threshold and one-day paused threshold, including suspended tabs and duplicated `sessionStorage` identities.
3. **IndexedDB integrity:** Is the v1 → v2 upgrade additive? Do chunk metadata and Blob writes remain atomic and correctly ordered under quota/transaction failures? Is note deletion’s cascade bounded and transactional?
4. **Lifecycle and races:** Do archive/trash preserve audio? Does permanent note deletion remove all linked chunks atomically after a clear acknowledgement? Consider concurrent tabs and deleting while another recorder is active.
5. **Backup/export:** Is the notes-only v1 backup scope clearly preserved? Does audio export use the stored MIME type safely, and are memory costs and browser download uncertainty communicated?
6. **Privacy and permission:** Is the microphone requested only after an explicit user action? Verify that there is no upload, telemetry or external request path in the audio feature.
7. **Browser evidence:** Distinguish source/unit evidence, fake-media Chromium runtime evidence, synthetic UI Lens rendering, and NOT RUN physical microphone/Safari/iPhone/process-kill/quota-scale claims.

## Review constraints

- The browser suite used Chromium `156.0.8078.4` with its fake media device; it did not open a physical microphone.
- UI Lens used synthetic note text and generated fake audio. The image set covers idle, active recording, saved audio, playback, permission error and interrupted partial audio at desktop and mobile viewports.
- 28 MVP tests, 31 document-engine tests, 8 MVP-02 browser scenarios, 13 MVP-01 regression scenarios, typecheck, production build and 12 UI Lens captures are reported PASS.
- Real microphone, Safari/iPhone, browser eviction, process termination, large/long recordings and quota exhaustion were NOT RUN.
- IndexedDB is chunked at roughly one-second `MediaRecorder` timeslices. Playback/export builds a Blob from all chunks, so temporary memory use scales with the recording size.

Return findings by severity with specific file/function evidence. Identify whether each concern is confirmed from code or needs runtime verification. Give a review verdict and any targeted changes needed before architecture acceptance. Do not select Sync Engine, add STT/cloud features, or initiate MVP-03.

# noteOS MVP-02 — Local Audio Recording & Playback

**Status: IMPLEMENTED; automated and Chromium fake-microphone acceptance PASS.** This handoff covers the approved MVP-02 scope only. It does not claim real-microphone, Safari, iPhone, background-recording, quota-scale or crash-proof results.

## User flows

- From an open note, the user explicitly chooses **Record audio** before the browser requests microphone access. Unsupported APIs, denied permission, missing microphones and storage failures produce visible messages.
- App navigation and note lifecycle changes are blocked while recording; users must stop/save first because background recording is unsupported.
- Chromium's supported `MediaRecorder` MIME type is selected at runtime. Recording uses one-second timeslices and writes each non-empty Blob chunk to IndexedDB in sequence. Pause/resume is shown only when the runtime recorder exposes both methods.
- **Stop and save** waits for queued chunk writes before marking a non-empty recording complete. Empty stops and write failures are not labeled complete.
- Recordings are listed under their note. Users can play/seek through the browser audio controls, rename, export the original MIME type with a matching extension, or confirm deletion.
- Reloading the recording tab marks its unfinished sessions interrupted. Unfinished recording sessions inactive for two minutes, and paused sessions inactive for one day, are marked interrupted on a later note open. Partial chunks remain available to play/export and are clearly labeled.
- Archive and Trash preserve audio. Permanent note deletion removes the note, linked recording metadata and chunks in the same IndexedDB transaction. The confirmation explains that audio is excluded from the notes backup and asks the user to acknowledge audio export/deletion.

## Storage and migration

Database `noteos-mvp-01` advances from version 1 to version 2. The upgrade leaves the `notes` object store and every existing note value intact, and additively creates:

| Store | Key and indexes | Contents |
| --- | --- | --- |
| `recordings` | `id`; indexes `noteId`, `status`, `updatedAt` | Stable recording/note IDs, title, MIME type, explicit state, creation/update times, duration, chunk count and owning tab ID |
| `recordingChunks` | `id = recordingId:sequence`; indexes `recordingId`, unique `[recordingId, sequence]` | Ordered binary `Blob` parts |

Recording states are `recording`, `paused`, `complete`, `interrupted` and `failed`. A unique live-session constraint is enforced transactionally per note: another active/paused session cannot start. The JSON ProseMirror document, its schema version and note revision are not modified by audio operations.

There is no server, sync, transcription or cloud request. New third-party dependencies: **none**. Runtime services are the browser's `getUserMedia`, `MediaRecorder`, IndexedDB, Blob and object URL APIs.

## Backup and deletion contract

The existing `noteos.local-backup` version 1 contract remains notes-only for backward compatibility. Audio is exported separately, one recording at a time, as a local browser download. The UI says the browser download was requested and cannot prove that the file was saved. Users who permanently delete a note are told to export recordings first; the transaction then cascades the note and all its linked media. Archiving and moving to Trash never remove media.

## Limits and risks

1. One-second timeslices reduce the amount of unsaved audio held by the application, but browser `MediaRecorder` buffering and scheduling are implementation-dependent. The latest chunk in memory may be lost on abrupt process termination. This is not background or crash-proof recording.
2. On tab reload the same tab ID is available through `sessionStorage`; a later open also marks stale `recording` sessions after two minutes and stale paused sessions after one day. A suspended/background tab may be mistaken for stale after the threshold. Background recording is explicitly unsupported.
3. IndexedDB quota, browser eviction, private-browsing restrictions and storage denial vary by browser. Write failure preserves already committed chunks as a `failed` partial recording; no quota capacity guarantee was measured.
4. Playback and export reassemble a recording's stored chunk Blobs into a browser Blob. Temporary memory use therefore grows with the full recording size; long-meeting behavior was not benchmarked. Storage is chunked, but complete-recording playback/export is not streaming.
5. The real microphone was not opened. Permission denial and write/quota errors were controlled browser fixtures, and audio input was Chromium's fake device. No iPhone, Safari, IME, OS interruption or cross-browser codecs were checked.
6. Object URLs and microphone tracks are released after playback resource replacement, deletion, stop and component cleanup. Unmount requests a stop and retains the last committed chunks; completion of asynchronous cleanup during browser termination is not guaranteed.
7. Existing mobile navigation has horizontal overflow visible in the UI Lens screenshots; this predates this audio feature and was not changed here.

      tx.onerror = () => reject(tx.error);

  });

import { assertNoteRecord, validateNoteDocument } from './note-validation.mjs';
export { NoteDocumentError } from './note-validation.mjs';

const DATABASE_NAME = 'noteos-mvp-01';
const DATABASE_VERSION = 2;
const STORE_NAME = 'notes';
const RECORDINGS_STORE = 'recordings';
const RECORDING_CHUNKS_STORE = 'recordingChunks';

export class NoteNotFoundError extends Error {
  constructor(id) {
    super(`Note ${id} was not found.`);
    this.name = 'NoteNotFoundError';
  }
}

export class NoteConflictError extends Error {
  constructor() {
    super('This note changed in another tab. The current version was kept.');
    this.name = 'NoteConflictError';
  }
}

export class ImportCollisionError extends Error {
  constructor(count) {
    super(`${count} note ID${count === 1 ? '' : 's'} already exist. No notes were imported.`);
    this.name = 'ImportCollisionError';
    this.count = count;
  }
}

export class NoteStateError extends Error {
  constructor(message) {
    super(message);
    this.name = 'NoteStateError';
  }
}

function requestResult(request) {
  return new Promise((resolve, reject) => {
    request.onsuccess = () => resolve(request.result);
    request.onerror = () => reject(request.error ?? new Error('IndexedDB request failed.'));
  });
}

function transactionResult(transaction) {
  return new Promise((resolve, reject) => {
    transaction.oncomplete = () => resolve();
    transaction.onabort = () => reject(transaction.error ?? new Error('IndexedDB transaction was aborted.'));
    transaction.onerror = () => reject(transaction.error ?? new Error('IndexedDB transaction failed.'));
  });
}

function abort(transaction, error) {
  try { transaction.abort(); } catch { /* The transaction may already be finished. */ }
  return error;
}

export function makeEmptyNote(now = Date.now(), id = crypto.randomUUID()) {
  return {
    id,
    title: 'Untitled note',
    document: { schemaVersion: 1, type: 'doc', content: [] },
    schemaVersion: 1,
    createdAt: now,
    updatedAt: now,
    lifecycle: 'active',
    revision: 0,
  };
}

function assertExpectedRevision(revision) {
  if (!Number.isInteger(revision) || revision < 0) throw new TypeError('An expected note revision is required.');
}

export function createNotesRepository(indexedDBFactory = globalThis.indexedDB, databaseName = DATABASE_NAME) {
  let databasePromise;

  function openDatabase() {
    if (!indexedDBFactory) return Promise.reject(new Error('This browser does not provide IndexedDB.'));
    if (!databasePromise) {
      databasePromise = new Promise((resolve, reject) => {
        const request = indexedDBFactory.open(databaseName, DATABASE_VERSION);
        request.onupgradeneeded = () => {
          const database = request.result;
          if (!database.objectStoreNames.contains(STORE_NAME)) {
            const store = database.createObjectStore(STORE_NAME, { keyPath: 'id' });
            store.createIndex('lifecycle', 'lifecycle', { unique: false });
            store.createIndex('updatedAt', 'updatedAt', { unique: false });
          }
          if (!database.objectStoreNames.contains(RECORDINGS_STORE)) {
            const recordings = database.createObjectStore(RECORDINGS_STORE, { keyPath: 'id' });
            recordings.createIndex('noteId', 'noteId', { unique: false });
            recordings.createIndex('status', 'status', { unique: false });
            recordings.createIndex('updatedAt', 'updatedAt', { unique: false });
          }
          if (!database.objectStoreNames.contains(RECORDING_CHUNKS_STORE)) {
            const chunks = database.createObjectStore(RECORDING_CHUNKS_STORE, { keyPath: 'id' });
            chunks.createIndex('recordingId', 'recordingId', { unique: false });
            chunks.createIndex('recordingSequence', ['recordingId', 'sequence'], { unique: true });
          }
        };
        request.onsuccess = () => {
          request.result.onversionchange = () => request.result.close();
          resolve(request.result);
        };
        request.onerror = () => reject(request.error ?? new Error('Could not open local note storage.'));
        request.onblocked = () => reject(new Error('Local note storage is open in another tab. Close older noteOS tabs and retry.'));
      }).catch((error) => {
        databasePromise = undefined;
        throw error;
      });
    }
    return databasePromise;
  }

  async function list() {
    const database = await openDatabase();
    const transaction = database.transaction(STORE_NAME, 'readonly');
    const done = transactionResult(transaction);
    const rows = await requestResult(transaction.objectStore(STORE_NAME).getAll());
    await done;
    return rows.sort((left, right) => Number(right.updatedAt) - Number(left.updatedAt));
  }

  async function get(id) {
    const database = await openDatabase();
    const transaction = database.transaction(STORE_NAME, 'readonly');
    const done = transactionResult(transaction);
    const row = await requestResult(transaction.objectStore(STORE_NAME).get(id));
    await done;
    return row ?? null;
  }

  async function create(note = makeEmptyNote()) {
    assertNoteRecord(note);
    const database = await openDatabase();
    const transaction = database.transaction(STORE_NAME, 'readwrite');
    const done = transactionResult(transaction);
    transaction.objectStore(STORE_NAME).add(note);
    await done;
    return note;
  }

  async function save(id, changes, expectedRevision) {
    assertExpectedRevision(expectedRevision);
    if (!changes || typeof changes.title !== 'string') throw new TypeError('A note title must be a string.');
    const validation = validateNoteDocument(changes.document, false);
    const database = await openDatabase();
    const transaction = database.transaction(STORE_NAME, 'readwrite');
    const done = transactionResult(transaction);
    const store = transaction.objectStore(STORE_NAME);

    try {
      const current = await requestResult(store.get(id));
      if (!current) throw abort(transaction, new NoteNotFoundError(id));
      if (current.revision !== expectedRevision) throw abort(transaction, new NoteConflictError());
      if (current.lifecycle === 'trashed') throw abort(transaction, new NoteStateError('Restore a trashed note before editing it.'));
      const updated = {
        ...current,
        title: changes.title,
        document: validation.document,
        updatedAt: Date.now(),
        revision: current.revision + 1,
      };
      store.put(updated);
      await done;
      return updated;
    } catch (error) {
      try { await done; } catch { /* Consume the abort before returning the original error. */ }
      throw error;
    }
  }

  async function setLifecycle(id, lifecycle, expectedRevision) {
    if (!['active', 'archived', 'trashed'].includes(lifecycle)) throw new TypeError('Invalid note lifecycle.');
    assertExpectedRevision(expectedRevision);
    const database = await openDatabase();
    const transaction = database.transaction(STORE_NAME, 'readwrite');
    const done = transactionResult(transaction);
    const store = transaction.objectStore(STORE_NAME);

    try {
      const current = await requestResult(store.get(id));
      if (!current) throw abort(transaction, new NoteNotFoundError(id));
      if (current.revision !== expectedRevision) throw abort(transaction, new NoteConflictError());
      if (current.lifecycle === 'trashed' && lifecycle === 'archived') {
        throw abort(transaction, new NoteStateError('Restore a trashed note before archiving it.'));
      }
      const updated = { ...current, lifecycle, updatedAt: Date.now(), revision: current.revision + 1 };
      store.put(updated);
      await done;
      return updated;
    } catch (error) {
      try { await done; } catch { /* Consume the abort before returning the original error. */ }
      throw error;
    }
  }

  async function deleteForever(id, expectedRevision) {
    assertExpectedRevision(expectedRevision);
    const database = await openDatabase();
    const transaction = database.transaction([STORE_NAME, RECORDINGS_STORE, RECORDING_CHUNKS_STORE], 'readwrite');
    const done = transactionResult(transaction);
    const store = transaction.objectStore(STORE_NAME);
    try {
      const current = await requestResult(store.get(id));
      if (!current) throw abort(transaction, new NoteNotFoundError(id));
      if (current.revision !== expectedRevision) throw abort(transaction, new NoteConflictError());
      if (current.lifecycle !== 'trashed') throw abort(transaction, new NoteStateError('Only trashed notes can be permanently deleted.'));
      const recordings = transaction.objectStore(RECORDINGS_STORE);
      const chunks = transaction.objectStore(RECORDING_CHUNKS_STORE);
      const linked = await requestResult(recordings.index('noteId').getAll(id));
      for (const recording of linked) {
        const keys = await requestResult(chunks.index('recordingId').getAllKeys(recording.id));
        for (const key of keys) chunks.delete(key);
        recordings.delete(recording.id);
      }
      store.delete(id);
      await done;
      return current;
    } catch (error) {
      try { await done; } catch { /* Consume the abort before returning the original error. */ }
      throw error;
    }
  }

  async function importNotes(notes, mode = 'merge') {
    if (!['merge', 'skip'].includes(mode)) throw new TypeError('Choose merge or skip.');
    if (!Array.isArray(notes)) throw new TypeError('Backup notes must be an array.');
    const ids = new Set();
    for (const note of notes) {
      if (!note || typeof note.id !== 'string' || !note.id || ids.has(note.id)) {
        throw new TypeError('The backup contains a missing or duplicate note ID.');
      }
      assertNoteRecord(note, { allowUnsupported: true });
      ids.add(note.id);
    }

    const database = await openDatabase();
    const transaction = database.transaction(STORE_NAME, 'readwrite');
    const done = transactionResult(transaction);
    const store = transaction.objectStore(STORE_NAME);
    const existing = await requestResult(store.getAll());
    const existingIds = new Set(existing.map((note) => note.id));
    const collisions = notes.filter((note) => existingIds.has(note.id)).length;
    if (mode === 'skip' && collisions > 0) {
      abort(transaction, new ImportCollisionError(collisions));
      try { await done; } catch { /* Expected: the all-or-nothing import was aborted. */ }
      throw new ImportCollisionError(collisions);
    }

    const additions = notes.filter((note) => !existingIds.has(note.id));
    for (const note of additions) store.add(note);
    await done;
    return { imported: additions.length, skipped: collisions };
  }

  return { list, get, create, save, setLifecycle, deleteForever, importNotes };
}

export const BACKUP_FORMAT = 'noteos.local-backup';
export const BACKUP_VERSION = 1;

export function searchableText(value) {
  return String(value ?? '')
    .normalize('NFD')
    .replace(/[\u0300-\u036f]/g, '')
    .replace(/[đĐ]/g, (character) => character === 'Đ' ? 'D' : 'd')
    .toLowerCase()
    .replace(/[^\p{L}\p{N}]+/gu, ' ')
    .trim();
}

function collectNodeText(node, output) {
  if (!node || typeof node !== 'object') return;
  if (node.type === 'text' && typeof node.text === 'string') output.push(node.text);
  for (const child of Array.isArray(node.content) ? node.content : []) collectNodeText(child, output);
}

  const pieces = [note?.title];
  collectNodeText(note?.document, pieces);
  return searchableText(pieces.join(' '));
}

}

}

export const JOURNAL_PREFIX = 'noteos:mvp01:recovery:';
export function recoveryStorage() { try { return globalThis.localStorage; } catch { return undefined; } }
const EPOCH_PREFIX = 'noteos:mvp01:deletion:';
export const sameContent = (left, right) => left?.title === right?.title && JSON.stringify(left?.document) === JSON.stringify(right?.document);
const epoch = (storage, id) => { try { return storage?.getItem(`${EPOCH_PREFIX}${encodeURIComponent(id)}`) ?? ''; } catch { return ''; } };

export function recoveryEntries(storage, id) {
  const result = [];
  try {
    const legacy = `${JOURNAL_PREFIX}${id}`;
    const prefix = `${JOURNAL_PREFIX}${encodeURIComponent(id)}:`;
    for (let index = 0; index < storage.length; index += 1) {
      const key = storage.key(index);
      if (key !== legacy && !key?.startsWith(prefix)) continue;
      const raw = storage.getItem(key);
      try { result.push({ key, raw, value: JSON.parse(raw) }); } catch { result.push({ key, raw, value: null }); }
    }
  } catch { /* Journal storage is best effort; IndexedDB remains authoritative. */ }
  return result;
}

export function clearRecoveryEntry(storage, entry) {
  try { if (storage.getItem(entry.key) === entry.raw) storage.removeItem(entry.key); } catch { /* Preserve on failure. */ }
}

export function recoveryCandidates(storage, note) {
  const candidates = [];
  for (const entry of recoveryEntries(storage, note.id)) {
    const draft = entry.value;
    let valid = false;
    try { valid = typeof draft?.title === 'string' && Number.isSafeInteger(draft.baseRevision) && draft.baseRevision >= 0 && validateNoteDocument(draft.document).status === 'supported'; } catch { /* Expose invalid recovery data without applying it. */ }
    if (valid && sameContent(draft, note)) { clearRecoveryEntry(storage, entry); continue; }
    const sameEpoch = (draft?.deletionEpoch ?? '') === epoch(storage, note.id);
    const sameInstance = draft?.recordCreatedAt === undefined || draft.recordCreatedAt === note.createdAt;
    const ownEarlierCommit = draft?.inFlight && note.revision === draft.inFlight.expectedRevision + 1 && sameContent(note, draft.inFlight);
    candidates.push({ ...entry, ...draft, valid, sameRevision: Boolean(valid && note.lifecycle === 'active' && sameEpoch && sameInstance && (draft.baseRevision === note.revision || ownEarlierCommit)) });
  }
  return candidates;
}

export function createRecoveryJournal(storage, note, writerId = crypto.randomUUID()) {
  const key = `${JOURNAL_PREFIX}${encodeURIComponent(note.id)}:${writerId}`;
  const deletionEpoch = epoch(storage, note.id);
  let lastRaw;
  return {
    isCurrent: () => epoch(storage, note.id) === deletionEpoch,
    write(draft, generation, baseRevision, inFlight = null) {
      try {
        lastRaw = JSON.stringify({ version: 2, writerId, generation, baseRevision, recordCreatedAt: note.createdAt, deletionEpoch, title: draft.title, document: draft.document, inFlight, updatedAt: Date.now() });
        storage.setItem(key, lastRaw);
        return true;
      } catch { return false; }
    },
    clear() { if (lastRaw !== undefined) clearRecoveryEntry(storage, { key, raw: lastRaw }); },
  };
}

// Call only after the IndexedDB delete committed. A changed or unsaved journal is retained.
export function finishDeletedNote(storage, note, capturedEntries) {
  try { storage.setItem(`${EPOCH_PREFIX}${encodeURIComponent(note.id)}`, crypto.randomUUID()); } catch { /* Best effort marker. */ }
  for (const entry of capturedEntries) {
    if (entry.value?.baseRevision <= note.revision && sameContent(entry.value, note)) clearRecoveryEntry(storage, entry);
  }
}

import { NoteConflictError } from './local-notes.js';
import { sameContent } from './recovery-journal.mjs';

/** @param {{note: any, repository: any, journal: any, onChange?: (state: any) => void}} options */
export function createSaveCoordinator({ note, repository, journal, onChange = () => {} }) {
  let saved = structuredClone(note);
  let draft = { title: note.title, document: structuredClone(note.document) };
  let generation = 0;
  let running = null;
  let pending = null;
  let error = null;
  const dirty = () => !sameContent(draft, saved);
  const snapshot = () => ({ note: saved, draft, generation, dirty: dirty(), inFlight: Boolean(pending), error });
  const notify = () => onChange(snapshot());
  const persist = () => journal.write(draft, generation, saved.revision, pending);
  function edit(next) {
    if (sameContent(next, draft)) return;
    draft = structuredClone(next); generation += 1; error = null;
    if (dirty() || pending) persist(); else journal.clear();
    notify();
  }
  function flush() {
    if (running) return running;
    if (!dirty()) return Promise.resolve({ ok: true, note: saved });
    running = (async () => {
      // Bound each drain. New edits continue through the existing debounce, never an error retry loop.
      for (let writes = 0; writes < 10 && dirty(); writes += 1) {
        if (!journal.isCurrent()) { error = new NoteConflictError(); notify(); return { ok: false, error }; }
        const target = structuredClone(draft);
        pending = { ...target, generation, expectedRevision: saved.revision };
        persist(); error = null; notify();
        try {
          saved = await repository.save(saved.id, target, saved.revision);
          pending = null;
          if (dirty()) persist(); else journal.clear();
          notify();
        } catch (cause) {
          pending = null; error = cause; persist(); notify();
          return { ok: false, error: cause };
        }
      }
      return dirty() ? { ok: false, pending: true } : { ok: true, note: saved };
    })().finally(() => { running = null; });
    return running;
  }
  async function transition(lifecycle) {
    const result = await flush();
    if (!result.ok) return result;
    try {
      if (!journal.isCurrent()) throw new NoteConflictError();
      if (saved.lifecycle !== lifecycle) saved = await repository.setLifecycle(saved.id, lifecycle, saved.revision);
      notify(); return { ok: true, note: saved };
    } catch (cause) { error = cause; notify(); return { ok: false, error: cause }; }
  }
  return { edit, flush, transition, snapshot, clearJournal: () => journal.clear() };
}

function formatDuration(durationMs: number) {
  const total = Math.floor(durationMs / 1000), hours = Math.floor(total / 3600), minutes = Math.floor((total % 3600) / 60), seconds = total % 60;
  return hours ? `${hours}:${String(minutes).padStart(2, '0')}:${String(seconds).padStart(2, '0')}` : `${minutes}:${String(seconds).padStart(2, '0')}`;
}
function recordingStatus(status: Recording['status']) {
  return ({ recording: 'Unfinished session — keep this noteOS tab open', paused: 'Paused session — resume in its original tab', complete: 'Saved', interrupted: 'Partial recording recovered', failed: 'Partially saved — storage failed' })[status];
}
function supportedMimeType() {
  if (typeof MediaRecorder === 'undefined') return null;
  return ['audio/webm;codecs=opus', 'audio/webm', 'audio/ogg;codecs=opus', 'audio/mp4'].find((type) => MediaRecorder.isTypeSupported(type)) ?? null;
}
function extension(mimeType: string) {
  const base = mimeType.split(';')[0].toLowerCase();
  if (base === 'audio/mp4' || base === 'audio/x-m4a') return 'm4a';
  if (base === 'audio/ogg') return 'ogg';
  if (base === 'audio/wav' || base === 'audio/wave') return 'wav';
  return 'webm';
}

+# noteOS MVP-02 — Local Audio Recording & Playback
+
+**Status: IMPLEMENTED; automated and Chromium fake-microphone acceptance PASS.** This handoff covers the approved MVP-02 scope only. It does not claim real-microphone, Safari, iPhone, background-recording, quota-scale or crash-proof results.
+
+## User flows
+
+- From an open note, the user explicitly chooses **Record audio** before the browser requests microphone access. Unsupported APIs, denied permission, missing microphones and storage failures produce visible messages.
+- App navigation and note lifecycle changes are blocked while recording; users must stop/save first because background recording is unsupported.
+- Chromium's supported `MediaRecorder` MIME type is selected at runtime. Recording uses one-second timeslices and writes each non-empty Blob chunk to IndexedDB in sequence. Pause/resume is shown only when the runtime recorder exposes both methods.
+- **Stop and save** waits for queued chunk writes before marking a non-empty recording complete. Empty stops and write failures are not labeled complete.
+- Recordings are listed under their note. Users can play/seek through the browser audio controls, rename, export the original MIME type with a matching extension, or confirm deletion.
+- Reloading the recording tab marks its unfinished sessions interrupted. Unfinished recording sessions inactive for two minutes, and paused sessions inactive for one day, are marked interrupted on a later note open. Partial chunks remain available to play/export and are clearly labeled.
+- Archive and Trash preserve audio. Permanent note deletion removes the note, linked recording metadata and chunks in the same IndexedDB transaction. The confirmation explains that audio is excluded from the notes backup and asks the user to acknowledge audio export/deletion.
+
+## Storage and migration
+
+Database `noteos-mvp-01` advances from version 1 to version 2. The upgrade leaves the `notes` object store and every existing note value intact, and additively creates:
+
+| Store | Key and indexes | Contents |
+| --- | --- | --- |
+| `recordings` | `id`; indexes `noteId`, `status`, `updatedAt` | Stable recording/note IDs, title, MIME type, explicit state, creation/update times, duration, chunk count and owning tab ID |
+| `recordingChunks` | `id = recordingId:sequence`; indexes `recordingId`, unique `[recordingId, sequence]` | Ordered binary `Blob` parts |
+
+Recording states are `recording`, `paused`, `complete`, `interrupted` and `failed`. A unique live-session constraint is enforced transactionally per note: another active/paused session cannot start. The JSON ProseMirror document, its schema version and note revision are not modified by audio operations.
+
+There is no server, sync, transcription or cloud request. New third-party dependencies: **none**. Runtime services are the browser's `getUserMedia`, `MediaRecorder`, IndexedDB, Blob and object URL APIs.
+
+## Backup and deletion contract
+
+The existing `noteos.local-backup` version 1 contract remains notes-only for backward compatibility. Audio is exported separately, one recording at a time, as a local browser download. The UI says the browser download was requested and cannot prove that the file was saved. Users who permanently delete a note are told to export recordings first; the transaction then cascades the note and all its linked media. Archiving and moving to Trash never remove media.

+## Limits and risks
+
+1. One-second timeslices reduce the amount of unsaved audio held by the application, but browser `MediaRecorder` buffering and scheduling are implementation-dependent. The latest chunk in memory may be lost on abrupt process termination. This is not background or crash-proof recording.
+2. On tab reload the same tab ID is available through `sessionStorage`; a later open also marks stale `recording` sessions after two minutes and stale paused sessions after one day. A suspended/background tab may be mistaken for stale after the threshold. Background recording is explicitly unsupported.
+3. IndexedDB quota, browser eviction, private-browsing restrictions and storage denial vary by browser. Write failure preserves already committed chunks as a `failed` partial recording; no quota capacity guarantee was measured.
+4. Playback and export reassemble a recording's stored chunk Blobs into a browser Blob. Temporary memory use therefore grows with the full recording size; long-meeting behavior was not benchmarked. Storage is chunked, but complete-recording playback/export is not streaming.
+5. The real microphone was not opened. Permission denial and write/quota errors were controlled browser fixtures, and audio input was Chromium's fake device. No iPhone, Safari, IME, OS interruption or cross-browser codecs were checked.
+6. Object URLs and microphone tracks are released after playback resource replacement, deletion, stop and component cleanup. Unmount requests a stop and retains the last committed chunks; completion of asynchronous cleanup during browser termination is not guaranteed.
+7. Existing mobile navigation has horizontal overflow visible in the UI Lens screenshots; this predates this audio feature and was not changed here.
