## 1. Mission

## 3. Native Persistence

Prefer `expo-sqlite` for native notes metadata and canonical JSON.

Requirements:
- Stable note IDs.
- Creation/update timestamps.
- Revision and lifecycle.
- Pin and tags.
- Full canonical document JSON.
- Schema-aware read-only behavior.
- Transactional updates and conflict protection.
- Safe database initialization and upgrades.

Do not introduce a second incompatible canonical document format.

Share validation/business logic with the Web project where practical.

Never downgrade or silently rewrite unknown-schema documents.

No backend or Sync Engine is required for MVP-04.

## 4. Notes Experience

Implement a clean native interface:

- Notes Home.
- Create and open notes.
- Edit title.
- Edit supported body content.
- Checklist creation and toggling.
- Pin/unpin.
- Tags.

- Archive, Trash and Restore.
- Safe delete confirmation.

Use native navigation and mobile-friendly input controls.

For rich-text editing, assess a locally bundled Tiptap editor through a controlled WebView bridge versus a deliberately limited native editor.

Prefer sharing the existing canonical document engine instead of reimplementing its schema.

Whichever approach is chosen:
- No remote editor webpage.
- No silent loss of formatting.
- Unsupported structures open read-only.
- Save/reload preserves exact supported JSON.
- Edits must not bypass revisions or discard drafts.

Document the choice and its actual limitations.

Do not build a full custom rich-text engine from scratch just for this prototype.

## 5. Native Audio

Use the Expo native audio APIs available in the installed SDK.

Implement:
- User-initiated microphone permission.
- Record, Stop and Save.
- Playback after reopening.
- Audio list under a note.
- Rename and delete.
- Export/share audio.
- Clear status on interruption and failed persistence.

Use persistent application document storage, not temporary cache as the only copy.

Store audio metadata in native SQLite.

Never mark a recording Complete until the native file has been finalized and verified accessible.

Treat metadata and file writes as separate operations with explicit recovery handling; do not claim they form one atomic SQLite transaction.

Preserve recoverable files where safe.

Do not implement background recording or lock-screen recording in this milestone.

Do not assume the Web's IndexedDB chunk model or Web Locks model applies natively.

# noteOS MVP-04 Native iPhone Prototype — Phase 00 Evidence

## Delivery summary

An isolated Expo iOS prototype now lives in `spikes/phase-00/gate1/mobile/`. It does not replace or write to the Web application's IndexedDB. The app source includes a notes home, editor navigation, create/open, title/body edit for the native subset, checklist edits, tags, pin, search, archive, trash, restore, permanent-delete confirmation, manual notes backup import/export and a local audio panel with record/stop/save/play/rename/delete/export flows.

SQLite stores the complete Web-shaped note record JSON along with indexed revision, lifecycle and update columns. Each save is a revision-checked SQL `UPDATE`, and note backup import uses a transaction with an all-or-nothing duplicate ID check. Lifecycle changes use the same revision compare-and-swap while preserving future-schema document JSON. Database initialization creates schema version 1 and does not clear existing data.

The prototype imports the existing Web canonical document validator and backup parser. The native editor is deliberately restricted to plain paragraph blocks and one top-level, single-level task list whose item contains one plain paragraph. It does not flatten headings, marks, links, code, nested lists, attachments or unknown nodes. Those documents display read-only. Future schema documents remain byte-preserved as JSON values and cannot be content-edited.

Audio uses `expo-audio` and requests microphone access only after the user taps Record. The recorder is configured to store in the app document directory. Stop verifies the finalized path and non-zero size before inserting `complete` metadata. Leaving the foreground triggers a best-effort stop and an `interrupted` recording row. Audio bytes and SQLite metadata are separate writes, so an abrupt OS termination between them can leave a recoverable file or metadata that needs inspection. Audio is excluded from notes backup and shared individually.

===== artifacts/review/noteOS-MVP-04-review/source/mobile/store.ts =====
import * as SQLite from 'expo-sqlite';
import { assertNoteRecord } from '../web/app/lib/note-validation.mjs';

export type Lifecycle = 'active' | 'archived' | 'trashed';
export type Note = {
  id: string; title: string; document: any; schemaVersion: number; createdAt: number; updatedAt: number;
  lifecycle: Lifecycle; revision: number; pinned: boolean; tags: string[];
};

let databasePromise: Promise<SQLite.SQLiteDatabase> | undefined;
export function database() {
  databasePromise ??= SQLite.openDatabaseAsync('noteos-mvp04.db').then(async db => {
    await db.execAsync('PRAGMA foreign_keys = ON; PRAGMA journal_mode = WAL;');
    const version = await db.getFirstAsync<{ user_version: number }>('PRAGMA user_version');
    if ((version?.user_version ?? 0) < 1) {
      await db.withTransactionAsync(async () => {
        await db.execAsync(`CREATE TABLE IF NOT EXISTS notes (
          id TEXT PRIMARY KEY NOT NULL,
          record_json TEXT NOT NULL,
          revision INTEGER NOT NULL,
          lifecycle TEXT NOT NULL CHECK(lifecycle IN ('active','archived','trashed')),
          updated_at INTEGER NOT NULL
        );
        CREATE INDEX IF NOT EXISTS notes_lifecycle_updated ON notes(lifecycle, updated_at DESC);
        CREATE TABLE IF NOT EXISTS recordings (
          id TEXT PRIMARY KEY NOT NULL,
          note_id TEXT NOT NULL REFERENCES notes(id) ON DELETE CASCADE,
          title TEXT NOT NULL,
          file_uri TEXT NOT NULL,
          status TEXT NOT NULL CHECK(status IN ('complete','interrupted')),
          created_at INTEGER NOT NULL
        );
        CREATE INDEX IF NOT EXISTS recordings_note ON recordings(note_id, created_at DESC);
        PRAGMA user_version = 1;`);
      });
    }
    return db;
  }).catch(error => { databasePromise = undefined; throw error; });
  return databasePromise;
}

function decode(record_json: string): Note {
  const record = JSON.parse(record_json) as Note;
  assertNoteRecord(record, { allowUnsupported: true });
  return record;
}
export async function listNotes() {
  const db = await database();
  const rows = await db.getAllAsync<{ record_json: string }>('SELECT record_json FROM notes ORDER BY updated_at DESC');
  return rows.map(row => decode(row.record_json));
}
export async function getNote(id: string) {
  const db = await database();
  const row = await db.getFirstAsync<{ record_json: string }>('SELECT record_json FROM notes WHERE id = ?', id);
  return row ? decode(row.record_json) : null;
}
export async function createNote(note: Note) {
  assertNoteRecord(note);
  const db = await database();
  await db.runAsync('INSERT INTO notes(id,record_json,revision,lifecycle,updated_at) VALUES(?,?,?,?,?)', note.id, JSON.stringify(note), note.revision, note.lifecycle, note.updatedAt);
}
export class RevisionConflictError extends Error { constructor() { super('This note changed since it was opened. Reload the saved version before editing.'); this.name = 'RevisionConflictError'; } }
export async function saveNote(note: Note, expectedRevision: number) {
  assertNoteRecord(note);
  const db = await database();
  const next = { ...note, revision: expectedRevision + 1, updatedAt: Date.now() };
  const result = await db.runAsync('UPDATE notes SET record_json = ?, revision = ?, lifecycle = ?, updated_at = ? WHERE id = ? AND revision = ?', JSON.stringify(next), next.revision, next.lifecycle, next.updatedAt, next.id, expectedRevision);
  if (result.changes !== 1) throw new RevisionConflictError();
  return next;
}
export async function setLifecycle(id: string, lifecycle: Lifecycle, expectedRevision: number) {
  const current = await getNote(id);

  if (result.changes !== 1) throw new RevisionConflictError();

}
export async function importNotes(notes: Note[]) {

import { validateCanonicalDocument } from '../web/packages/document-engine/src/index.js';

export type CanonicalDocument = { schemaVersion: number; type: 'doc'; content: any[]; [key: string]: any };

function plainText(node: any): string | null {
  if (!node || typeof node !== 'object') return null;
  if (node.type === 'text' && typeof node.text === 'string' && !/[\r\n]/u.test(node.text) && !node.marks && Object.keys(node).every(k => ['type', 'text'].includes(k))) return node.text;
  return null;
}

function paragraphText(node: any): string | null {
  if (!node || node.type !== 'paragraph' || (node.attrs && Object.keys(node.attrs).length) || Object.keys(node).some(k => !['type', 'content'].includes(k))) return null;
  if (!Array.isArray(node.content)) return '';
  let output = '';
  for (const item of node.content) {
    const text = plainText(item);
    if (text === null) return null;
    output += text;
  }
  return output;
}

export function documentToNativeModel(document: CanonicalDocument): { editable: boolean; reason?: string; paragraphs: string[]; tasks: { text: string; checked: boolean }[] } {
  const validation = validateCanonicalDocument(document);
  if (validation.status !== 'supported') return { editable: false, reason: validation.issues?.[0]?.message ?? 'Unknown schema; preserved read-only.', paragraphs: [], tasks: [] };
  if (document.schemaVersion !== 1 || document.type !== 'doc' || Object.keys(document).some(k => !['schemaVersion', 'type', 'content'].includes(k))) return { editable: false, reason: 'Document wrapper is outside the native editor subset.', paragraphs: [], tasks: [] };
  const paragraphs: string[] = [], tasks: { text: string; checked: boolean }[] = [];
  let seenTasks = false;
  for (const block of document.content) {
    if (block.type === 'paragraph' && !seenTasks) {
      const text = paragraphText(block);
      if (text === null) return { editable: false, reason: 'Rich text or paragraph attributes are preserved read-only.', paragraphs: [], tasks: [] };
      paragraphs.push(text);
      continue;
    }
    if (block.type === 'taskList' && !seenTasks && Object.keys(block).every(k => ['type', 'content'].includes(k)) && Array.isArray(block.content)) {
      seenTasks = true;
      for (const item of block.content) {
        if (item.type !== 'taskItem' || typeof item.attrs?.checked !== 'boolean' || Object.keys(item).some(k => !['type', 'attrs', 'content'].includes(k)) || Object.keys(item.attrs).some(k => k !== 'checked') || !Array.isArray(item.content) || item.content.length !== 1) return { editable: false, reason: 'Nested or decorated checklist content is preserved read-only.', paragraphs: [], tasks: [] };
        const text = paragraphText(item.content[0]);
        if (text === null) return { editable: false, reason: 'Rich checklist content is preserved read-only.', paragraphs: [], tasks: [] };
        tasks.push({ text, checked: item.attrs.checked });
      }
      continue;
    }
    return { editable: false, reason: 'This canonical structure is outside the native editor subset and is preserved read-only.', paragraphs: [], tasks: [] };
  }
  return { editable: true, paragraphs, tasks };
}

export function nativeModelToDocument(paragraphs: string[], tasks: { text: string; checked: boolean }[]): CanonicalDocument {
  const content: any[] = paragraphs.map(text => ({ type: 'paragraph', ...(text.length ? { content: [{ type: 'text', text }] } : {}) }));
  if (tasks.length) content.push({ type: 'taskList', content: tasks.map(task => ({ type: 'taskItem', attrs: { checked: task.checked }, content: [{ type: 'paragraph', ...(task.text.length ? { content: [{ type: 'text', text: task.text }] } : {}) }] })) });
  const document = { schemaVersion: 1, type: 'doc' as const, content };
  const validation = validateCanonicalDocument(document);
  if (validation.status !== 'supported') throw new Error(validation.issues?.[0]?.message ?? 'The edited document failed canonical validation.');
  return document;
}

import test from 'node:test';

const doc = { schemaVersion: 1, type: 'doc', content: [
  { type: 'paragraph', content: [{ type: 'text', text: 'Xin chào 日本語' }] },
  { type: 'taskList', content: [{ type: 'taskItem', attrs: { checked: true }, content: [{ type: 'paragraph', content: [{ type: 'text', text: 'Đã xong' }] }] }, { type: 'taskItem', attrs: { checked: false }, content: [{ type: 'paragraph' }] }] },
] };

test('supported paragraph and checklist subset round-trips through native model', () => {
  const model = documentToNativeModel(doc);
  assert.equal(model.editable, true);
  assert.deepEqual(nativeModelToDocument(model.paragraphs, model.tasks), doc);
});

test('unsupported canonical structures and future schema remain read-only without changing bytes', () => {
  const documents = [
    { schemaVersion: 1, type: 'doc', content: [{ type: 'heading', attrs: { level: 1 }, content: [{ type: 'text', text: 'Heading' }] }] },
    { schemaVersion: 2, type: 'doc', content: [{ type: 'futureBlock', payload: { keep: true } }] },
  ];
  for (const document of documents) {
    const original = JSON.stringify(document);
    assert.equal(documentToNativeModel(document).editable, false);
    assert.equal(JSON.stringify(document), original);
  }
});

test('native record uses the Web notes-only backup v1 contract and keeps checklist state', () => {
  const note = { id: 'synthetic-note', title: 'Gate A fixture', document: doc, schemaVersion: 1, createdAt: 10, updatedAt: 11, lifecycle: 'active', revision: 2, pinned: true, tags: ['Vietnamese', '東京'] };
  const parsed = parseBackup(JSON.stringify(makeBackup([note], '2026-10-21T00:00:00.000Z')));
  assert.equal(parsed.format, 'noteos.local-backup');
  assert.deepEqual(parsed.notes[0], note);
  assert.equal(engine.validateCanonicalDocument(parsed.notes[0].document).status, 'supported');
  assert.deepEqual(parsed.notes[0].document.content[1].content.map(item => item.attrs.checked), [true, false]);
});
