Recommended · disaster recovery & migration

Full Archive V2

All active, archived and trashed notes, canonical documents, metadata, and original audio bytes in one checksum-validated TAR archive. Interrupted or failed recordings retain their saved chunks and partial status.

Stop and finalize active recordings in every tab before exporting. Export is blocked while any session is recording or paused. An empty or damaged recording is never silently treated as complete.

Up to 1 GiB per archive and 512 MiB per audio file. Large archives may need substantial browser memory. Everything stays on this device.

Legacy JSON V1 · notes only

Includes all notes and note metadata for compatibility with earlier noteOS versions. Does NOT include audio. Use Full Archive V2 for notes and voice recordings together.

Restore from a backup

All archive checks finish before any data is written. Future document schemas are preserved read-only. Restoring never overwrites existing notes or audio.

If an ID already exists

A note with a conflicting note, recording or chunk ID is skipped together with all its recordings.
