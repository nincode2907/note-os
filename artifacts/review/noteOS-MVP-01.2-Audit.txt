# noteOS MVP-01.2 — Data Safety Patch

Scope: verified F-01–F-05 only, IndexedDB database v1 and canonical JSON v1 retained. No dependency, sync engine, AI, voice, cloud, or production deployment change.

**Result: all five findings FIXED in the implemented and tested scope. Ready for Lead Architect review/acceptance with the durability limits below.** This is not a guarantee against browser eviction, unavailable recovery storage, or OS/process termination.

## Findings and changes

| Finding | Status | Root cause and fix | Evidence |
| --- | --- | --- | --- |
| F-01 live editor recovery | **FIXED** | React draft state changed while mounted Tiptap retained old content. Recovery now validates with the canonical engine, uses Tiptap 3.32.0 `setContent(json, { emitUpdate: false, errorOnInvalidContent: true })`, then updates React/coordinator and awaits a save. Original journals remain on apply/save failure. A concurrent revision forces recovery as a separate note. Explicitly keeping the saved version also resets the live editor after a failed recovery save. | Browser covers Old body → failed write → Recovered body/title → restore → more typing → save/reload; failed recovery save/discard; concurrent recovery/copy. |
| F-02 lifecycle after failed save | **FIXED** | Save failures were consumed, and lifecycle adopted a fresh DB revision. `flush()`/`transition()` now return explicit results. Transition uses the coordinator's committed revision; no DB reread bypasses a conflict. Failure prevents navigation and preserves the draft. Clean drafts do not produce a save/revision increment. Trashed/future-schema records can take allowed lifecycle actions without being rewritten. | Stale Archive/Trash in two tabs, injected failure + Archive, immediate Archive, normal lifecycle and clean revision-count assertions. |
| F-03 overlapping saves/newer journal | **FIXED** | Independent calls raced and older completions cleared the shared recovery key. A single-note coordinator serializes writes, records generations and in-flight snapshots, drains newer drafts with the next committed revision, and only clears its own journal when current content is committed. Each tab has its own journal key. Drains are bounded; failures stop without an automatic retry loop. Reopening uses content/revision evidence rather than timestamp ordering. | Deferred A/B/C tests, failed in-flight save, cross-tab conflict, simultaneous save/lifecycle; real browser IndexedDB transaction held until test releases it while B/C arrive. |
| F-04 debounce navigation loss | **FIXED** | Links could unmount the editor before debounce. Back/sidebar/brand links now use Next's documented `onNavigate` cancellation hook and await the editor flush. Lifecycle/copy routes navigate only after their explicit operation succeeds. Failure remains on the editor with retry/copy feedback. No async unmount save is used. | Back/sidebar clicks in less than 650 ms preserve current content on reopen; failed sidebar flush stays on editor and retains its journal. |
| F-05 journal cleanup/import mismatch | **FIXED** | Delete left old journals; parser and repository had different document rules. Confirmed delete returns the deleted record, removes only captured unchanged journals matching committed content, retains newer/other-tab drafts and marks the deletion epoch. Retained pre-delete journals can only recover as copies after same-ID import. Parser/repository share record/canonical validation; future documents remain unmodified. Missing note routes now show not-found instead of silently recreating a deleted ID. | Delete/reimport browser test; stale/new/concurrently changed/unrelated journal tests; shared parser/repository rejection and future preservation tests. |

- `app/lib/note-validation.mjs`: the common metadata/canonical validation boundary. It rejects corrupt wrappers/known trees and invalid record metadata, while retaining valid future/unsupported documents for read-only use.
- `app/ui/navigation-guard.tsx`, editor and app shell: app navigation flush, live recovery application, retry/copy and failure feedback.
- Repository/import/lifecycle changes reuse the existing IndexedDB transactions. No IndexedDB migration or canonical schema change was made.

## Remaining durability limits and review points

1. IndexedDB is primary storage. localStorage recovery journals are synchronous best-effort checkpoints after edit events; storage can be denied, full, cleared or evicted. Neither this patch nor a successful download request guarantees durable backup.
2. Application-controlled links/lifecycle await flush. Refresh/tab close uses a `beforeunload` warning when dirty/in flight; browser back/forward, OS termination and process crash rely on the journal. Async IndexedDB completion during unload is not guaranteed. IME composition that never emits an edit update is not covered.
3. Journal cleanup/deletion markers are separate localStorage operations after the IndexedDB deletion commits, not one atomic transaction across the two stores. Changed/ambiguous journals are retained rather than discarded; same-ID retained drafts are offered as copies when the marker is available. Multi-tab deletion/reimport with unavailable localStorage is not a fully verified atomic incarnation protocol.
4. Recovery journals and backup files remain unencrypted local data. The existing dependency audit finding through the unused-in-MVP WatermelonDB candidate from MVP-01.1 remains unchanged; no dependencies changed or audit auto-fix ran here.
5. No additional confirmed data-loss defect remains in the exercised scope. Browser eviction/quota, full process-kill durability, large documents and real-iPhone behavior still need dedicated evidence before broader guarantees.

+export function createSaveCoordinator({ note, repository, journal, onChange = () => {} }) {
+  let saved = structuredClone(note);
+  let draft = { title: note.title, document: structuredClone(note.document) };
+  let generation = 0;
+  let running = null;
+  let pending = null;
+  let error = null;
+  const dirty = () => !sameContent(draft, saved);
+  const snapshot = () => ({ note: saved, draft, generation, dirty: dirty(), inFlight: Boolean(pending), error });
+  const notify = () => onChange(snapshot());
+  const persist = () => journal.write(draft, generation, saved.revision, pending);
+  function edit(next) {
+    if (sameContent(next, draft)) return;
+    draft = structuredClone(next); generation += 1; error = null;
+    if (dirty() || pending) persist(); else journal.clear();
+    notify();
+  }
+  function flush() {
+    if (running) return running;
+    if (!dirty()) return Promise.resolve({ ok: true, note: saved });
+    running = (async () => {
+      // Bound each drain. New edits continue through the existing debounce, never an error retry loop.
+      for (let writes = 0; writes < 10 && dirty(); writes += 1) {
+        if (!journal.isCurrent()) { error = new NoteConflictError(); notify(); return { ok: false, error }; }
+        const target = structuredClone(draft);
+        pending = { ...target, generation, expectedRevision: saved.revision };
+        persist(); error = null; notify();
+        try {
+          saved = await repository.save(saved.id, target, saved.revision);
+          pending = null;
+          if (dirty()) persist(); else journal.clear();
+          notify();
+        } catch (cause) {
+          pending = null; error = cause; persist(); notify();
+          return { ok: false, error: cause };
+        }
+      }
+      return dirty() ? { ok: false, pending: true } : { ok: true, note: saved };
+    })().finally(() => { running = null; });
+    return running;
+  }
+  async function transition(lifecycle) {
+    const result = await flush();
+    if (!result.ok) return result;
+    try {
+      if (!journal.isCurrent()) throw new NoteConflictError();
+      if (saved.lifecycle !== lifecycle) saved = await repository.setLifecycle(saved.id, lifecycle, saved.revision);
+      notify(); return { ok: true, note: saved };
+    } catch (cause) { error = cause; notify(); return { ok: false, error: cause }; }
+  }
+  return { edit, flush, transition, snapshot, clearJournal: () => journal.clear() };

+type Guard = () => Promise<boolean>;
+const NavigationContext = createContext<{ register: (guard: Guard) => () => void; navigate: (href: string) => Promise<void> } | null>(null);
+
+export function NavigationGuardProvider({ children }: { children: React.ReactNode }) {
+  const router = useRouter();
+  const guard = useRef<Guard | null>(null);
+  const register = useCallback((next: Guard) => { guard.current = next; return () => { if (guard.current === next) guard.current = null; }; }, []);
+  const navigate = useCallback(async (href: string) => { if (!guard.current || await guard.current()) router.push(href); }, [router]);
+  const value = useMemo(() => ({ register, navigate }), [register, navigate]);
+  return <NavigationContext.Provider value={value}>{children}</NavigationContext.Provider>;
+}

+export function useNavigationGuard(guard: Guard) {
+  const navigation = useContext(NavigationContext);
+  useEffect(() => navigation?.register(guard), [navigation, guard]);

import { assertNoteRecord, validateNoteDocument } from './note-validation.mjs';
export { NoteDocumentError } from './note-validation.mjs';

const DATABASE_NAME = 'noteos-mvp-01';
const DATABASE_VERSION = 1;
const STORE_NAME = 'notes';

export class NoteNotFoundError extends Error {
  constructor(id) {
    super(`Note ${id} was not found.`);
    this.name = 'NoteNotFoundError';
  }
}

export class NoteConflictError extends Error {
  constructor() {
    super('This note changed in another tab. The current version was kept.');
    this.name = 'NoteConflictError';
  }
}

export class ImportCollisionError extends Error {
  constructor(count) {
    super(`${count} note ID${count === 1 ? '' : 's'} already exist. No notes were imported.`);
    this.name = 'ImportCollisionError';
    this.count = count;
  }
}

export class NoteStateError extends Error {
  constructor(message) {
    super(message);
    this.name = 'NoteStateError';
  }
}

function requestResult(request) {
  return new Promise((resolve, reject) => {
    request.onsuccess = () => resolve(request.result);
    request.onerror = () => reject(request.error ?? new Error('IndexedDB request failed.'));
  });
}

function transactionResult(transaction) {
  return new Promise((resolve, reject) => {
    transaction.oncomplete = () => resolve();
    transaction.onabort = () => reject(transaction.error ?? new Error('IndexedDB transaction was aborted.'));
    transaction.onerror = () => reject(transaction.error ?? new Error('IndexedDB transaction failed.'));
  });
}

function abort(transaction, error) {
  try { transaction.abort(); } catch { /* The transaction may already be finished. */ }
  return error;
}

export function makeEmptyNote(now = Date.now(), id = crypto.randomUUID()) {
  return {
    id,
    title: 'Untitled note',
    document: { schemaVersion: 1, type: 'doc', content: [] },
    schemaVersion: 1,
    createdAt: now,
    updatedAt: now,
    lifecycle: 'active',
    revision: 0,
  };
}

function assertExpectedRevision(revision) {
  if (!Number.isInteger(revision) || revision < 0) throw new TypeError('An expected note revision is required.');
}

export function createNotesRepository(indexedDBFactory = globalThis.indexedDB, databaseName = DATABASE_NAME) {
  let databasePromise;

  function openDatabase() {
    if (!indexedDBFactory) return Promise.reject(new Error('This browser does not provide IndexedDB.'));
    if (!databasePromise) {
      databasePromise = new Promise((resolve, reject) => {
        const request = indexedDBFactory.open(databaseName, DATABASE_VERSION);
        request.onupgradeneeded = () => {
          const database = request.result;
          const store = database.createObjectStore(STORE_NAME, { keyPath: 'id' });
          store.createIndex('lifecycle', 'lifecycle', { unique: false });
          store.createIndex('updatedAt', 'updatedAt', { unique: false });
        };
        request.onsuccess = () => {
          request.result.onversionchange = () => request.result.close();
          resolve(request.result);
        };
        request.onerror = () => reject(request.error ?? new Error('Could not open local note storage.'));
        request.onblocked = () => reject(new Error('Local note storage is open in another tab. Close older noteOS tabs and retry.'));
      }).catch((error) => {
        databasePromise = undefined;
        throw error;
      });
    }
    return databasePromise;
  }

  async function list() {
    const database = await openDatabase();
    const transaction = database.transaction(STORE_NAME, 'readonly');
    const done = transactionResult(transaction);
    const rows = await requestResult(transaction.objectStore(STORE_NAME).getAll());
    await done;
    return rows.sort((left, right) => Number(right.updatedAt) - Number(left.updatedAt));
  }

  async function get(id) {
    const database = await openDatabase();
    const transaction = database.transaction(STORE_NAME, 'readonly');
    const done = transactionResult(transaction);
    const row = await requestResult(transaction.objectStore(STORE_NAME).get(id));
    await done;
    return row ?? null;
  }

  async function create(note = makeEmptyNote()) {
    assertNoteRecord(note);
    const database = await openDatabase();
    const transaction = database.transaction(STORE_NAME, 'readwrite');
    const done = transactionResult(transaction);
    transaction.objectStore(STORE_NAME).add(note);
    await done;
    return note;
  }

  async function save(id, changes, expectedRevision) {
    assertExpectedRevision(expectedRevision);
    if (!changes || typeof changes.title !== 'string') throw new TypeError('A note title must be a string.');
    const validation = validateNoteDocument(changes.document, false);
    const database = await openDatabase();
    const transaction = database.transaction(STORE_NAME, 'readwrite');
    const done = transactionResult(transaction);
    const store = transaction.objectStore(STORE_NAME);

    try {
      const current = await requestResult(store.get(id));
      if (!current) throw abort(transaction, new NoteNotFoundError(id));
      if (current.revision !== expectedRevision) throw abort(transaction, new NoteConflictError());
      if (current.lifecycle === 'trashed') throw abort(transaction, new NoteStateError('Restore a trashed note before editing it.'));
      const updated = {
        ...current,
        title: changes.title,
        document: validation.document,
        updatedAt: Date.now(),
        revision: current.revision + 1,
      };
      store.put(updated);
      await done;
      return updated;
    } catch (error) {
      try { await done; } catch { /* Consume the abort before returning the original error. */ }
      throw error;
    }
  }

  async function setLifecycle(id, lifecycle, expectedRevision) {
    if (!['active', 'archived', 'trashed'].includes(lifecycle)) throw new TypeError('Invalid note lifecycle.');
    assertExpectedRevision(expectedRevision);
    const database = await openDatabase();
    const transaction = database.transaction(STORE_NAME, 'readwrite');
    const done = transactionResult(transaction);
    const store = transaction.objectStore(STORE_NAME);

    try {
      const current = await requestResult(store.get(id));
      if (!current) throw abort(transaction, new NoteNotFoundError(id));
      if (current.revision !== expectedRevision) throw abort(transaction, new NoteConflictError());
      if (current.lifecycle === 'trashed' && lifecycle === 'archived') {
        throw abort(transaction, new NoteStateError('Restore a trashed note before archiving it.'));
      }
      const updated = { ...current, lifecycle, updatedAt: Date.now(), revision: current.revision + 1 };
      store.put(updated);
      await done;
      return updated;
    } catch (error) {
      try { await done; } catch { /* Consume the abort before returning the original error. */ }
      throw error;
    }
  }

  async function deleteForever(id, expectedRevision) {
    assertExpectedRevision(expectedRevision);
    const database = await openDatabase();
    const transaction = database.transaction(STORE_NAME, 'readwrite');
    const done = transactionResult(transaction);
    const store = transaction.objectStore(STORE_NAME);
    try {
      const current = await requestResult(store.get(id));
      if (!current) throw abort(transaction, new NoteNotFoundError(id));
      if (current.revision !== expectedRevision) throw abort(transaction, new NoteConflictError());
      if (current.lifecycle !== 'trashed') throw abort(transaction, new NoteStateError('Only trashed notes can be permanently deleted.'));
      store.delete(id);
      await done;
      return current;
    } catch (error) {
      try { await done; } catch { /* Consume the abort before returning the original error. */ }
      throw error;
    }
  }

  async function importNotes(notes, mode = 'merge') {
    if (!['merge', 'skip'].includes(mode)) throw new TypeError('Choose merge or skip.');
    if (!Array.isArray(notes)) throw new TypeError('Backup notes must be an array.');
    const ids = new Set();
    for (const note of notes) {
      if (!note || typeof note.id !== 'string' || !note.id || ids.has(note.id)) {
        throw new TypeError('The backup contains a missing or duplicate note ID.');
      }
      assertNoteRecord(note, { allowUnsupported: true });
      ids.add(note.id);
    }

    const database = await openDatabase();
    const transaction = database.transaction(STORE_NAME, 'readwrite');
    const done = transactionResult(transaction);
    const store = transaction.objectStore(STORE_NAME);
    const existing = await requestResult(store.getAll());
    const existingIds = new Set(existing.map((note) => note.id));
    const collisions = notes.filter((note) => existingIds.has(note.id)).length;
    if (mode === 'skip' && collisions > 0) {
      abort(transaction, new ImportCollisionError(collisions));
      try { await done; } catch { /* Expected: the all-or-nothing import was aborted. */ }
      throw new ImportCollisionError(collisions);
    }

    const additions = notes.filter((note) => !existingIds.has(note.id));
    for (const note of additions) store.add(note);
    await done;
    return { imported: additions.length, skipped: collisions };
  }

  return { list, get, create, save, setLifecycle, deleteForever, importNotes };
}

import { assertNoteRecord } from './note-validation.mjs';

export const BACKUP_FORMAT = 'noteos.local-backup';
export const BACKUP_VERSION = 1;

export function searchableText(value) {
  return String(value ?? '')
    .normalize('NFD')
    .replace(/[\u0300-\u036f]/g, '')
    .replace(/[đĐ]/g, (character) => character === 'Đ' ? 'D' : 'd')
    .toLowerCase()
    .replace(/[^\p{L}\p{N}]+/gu, ' ')
    .trim();
}

function collectNodeText(node, output) {
  if (!node || typeof node !== 'object') return;
  if (node.type === 'text' && typeof node.text === 'string') output.push(node.text);
  for (const child of Array.isArray(node.content) ? node.content : []) collectNodeText(child, output);
}

export function noteSearchText(note) {
  const pieces = [note?.title];
  collectNodeText(note?.document, pieces);
  return searchableText(pieces.join(' '));
}

export function filterNotes(notes, query, lifecycle) {
  const normalized = searchableText(query);
  return notes.filter((note) => note.lifecycle === lifecycle && (!normalized || noteSearchText(note).includes(normalized)));
}

export function makeBackup(notes, exportedAt = new Date().toISOString()) {
  return { format: BACKUP_FORMAT, version: BACKUP_VERSION, exportedAt, notes };
}

export function parseBackup(input) {
  let bundle;
  try { bundle = typeof input === 'string' ? JSON.parse(input) : input; }
  catch { throw new TypeError('Backup file is not valid JSON.'); }
  if (!bundle || bundle.format !== BACKUP_FORMAT || bundle.version !== BACKUP_VERSION || !Array.isArray(bundle.notes)) {
    throw new TypeError('This file is not a supported noteOS backup (version 1).');
  }
  const ids = new Set();
  for (const note of bundle.notes) {
    if (!note || typeof note.id !== 'string' || !note.id.trim() || ids.has(note.id)) throw new TypeError('Backup contains a missing or duplicate note ID.');
    assertNoteRecord(note, { allowUnsupported: true });
    ids.add(note.id);
  }
  return bundle;
}

export function titleFromDocument(document) {
  const text = [];
  collectNodeText(document, text);
  return text.join('').split('\n').map((line) => line.trim()).find(Boolean)?.slice(0, 80) || 'Untitled note';
}

export function formatSavedAt(timestamp) {
  if (!timestamp) return '';
  return new Intl.DateTimeFormat(undefined, { hour: 'numeric', minute: '2-digit' }).format(new Date(timestamp));
}

export class NoteDocumentError extends Error {
  constructor(message, issues = []) { super(message); this.name = 'NoteDocumentError'; this.issues = issues; }
}

export function validateNoteDocument(document, allowUnsupported = false) {
  if (!document || Array.isArray(document) || document.type !== 'doc' || !Array.isArray(document.content) || !Number.isSafeInteger(document.schemaVersion) || document.schemaVersion < 1) {
    throw new NoteDocumentError('A canonical document requires a version, doc root and content array.');
  }
  const result = validateCanonicalDocument(document);
  if (result.status === 'invalid' || (!allowUnsupported && result.status !== 'supported')) {
    throw new NoteDocumentError(result.issues?.[0]?.message ?? 'The note document cannot be safely written.', result.issues ?? []);
  }
  return result;
}

export function assertNoteRecord(note, { allowUnsupported = false } = {}) {
  if (!note || typeof note.id !== 'string' || !note.id.trim()) throw new TypeError('A note requires a stable ID.');
  if (typeof note.title !== 'string' || !Number.isSafeInteger(note.schemaVersion) || note.schemaVersion < 1 || !Number.isSafeInteger(note.createdAt) || note.createdAt < 0 || !Number.isSafeInteger(note.updatedAt) || note.updatedAt < 0 || !['active', 'archived', 'trashed'].includes(note.lifecycle) || !Number.isSafeInteger(note.revision) || note.revision < 0) {
    throw new TypeError(`Backup note “${note.id}” has invalid metadata.`);
  }
  validateNoteDocument(note.document, allowUnsupported);
}

export const JOURNAL_PREFIX = 'noteos:mvp01:recovery:';
export function recoveryStorage() { try { return globalThis.localStorage; } catch { return undefined; } }
const EPOCH_PREFIX = 'noteos:mvp01:deletion:';
export const sameContent = (left, right) => left?.title === right?.title && JSON.stringify(left?.document) === JSON.stringify(right?.document);
const epoch = (storage, id) => { try { return storage?.getItem(`${EPOCH_PREFIX}${encodeURIComponent(id)}`) ?? ''; } catch { return ''; } };

export function recoveryEntries(storage, id) {
  const result = [];
  try {
    const legacy = `${JOURNAL_PREFIX}${id}`;
    const prefix = `${JOURNAL_PREFIX}${encodeURIComponent(id)}:`;
    for (let index = 0; index < storage.length; index += 1) {
      const key = storage.key(index);
      if (key !== legacy && !key?.startsWith(prefix)) continue;
      const raw = storage.getItem(key);
      try { result.push({ key, raw, value: JSON.parse(raw) }); } catch { result.push({ key, raw, value: null }); }
    }
  } catch { /* Journal storage is best effort; IndexedDB remains authoritative. */ }
  return result;
}

export function clearRecoveryEntry(storage, entry) {
  try { if (storage.getItem(entry.key) === entry.raw) storage.removeItem(entry.key); } catch { /* Preserve on failure. */ }
}

export function recoveryCandidates(storage, note) {
  const candidates = [];
  for (const entry of recoveryEntries(storage, note.id)) {
    const draft = entry.value;
    let valid = false;
    try { valid = typeof draft?.title === 'string' && Number.isSafeInteger(draft.baseRevision) && draft.baseRevision >= 0 && validateNoteDocument(draft.document).status === 'supported'; } catch { /* Expose invalid recovery data without applying it. */ }
    if (valid && sameContent(draft, note)) { clearRecoveryEntry(storage, entry); continue; }
    const sameEpoch = (draft?.deletionEpoch ?? '') === epoch(storage, note.id);
    const sameInstance = draft?.recordCreatedAt === undefined || draft.recordCreatedAt === note.createdAt;
    const ownEarlierCommit = draft?.inFlight && note.revision === draft.inFlight.expectedRevision + 1 && sameContent(note, draft.inFlight);
    candidates.push({ ...entry, ...draft, valid, sameRevision: Boolean(valid && note.lifecycle === 'active' && sameEpoch && sameInstance && (draft.baseRevision === note.revision || ownEarlierCommit)) });
  }
  return candidates;
}

export function createRecoveryJournal(storage, note, writerId = crypto.randomUUID()) {
  const key = `${JOURNAL_PREFIX}${encodeURIComponent(note.id)}:${writerId}`;
  const deletionEpoch = epoch(storage, note.id);
  let lastRaw;
  return {
    isCurrent: () => epoch(storage, note.id) === deletionEpoch,
    write(draft, generation, baseRevision, inFlight = null) {
      try {
        lastRaw = JSON.stringify({ version: 2, writerId, generation, baseRevision, recordCreatedAt: note.createdAt, deletionEpoch, title: draft.title, document: draft.document, inFlight, updatedAt: Date.now() });
        storage.setItem(key, lastRaw);
        return true;
      } catch { return false; }
    },
    clear() { if (lastRaw !== undefined) clearRecoveryEntry(storage, { key, raw: lastRaw }); },
  };
}

// Call only after the IndexedDB delete committed. A changed or unsaved journal is retained.
export function finishDeletedNote(storage, note, capturedEntries) {
  try { storage.setItem(`${EPOCH_PREFIX}${encodeURIComponent(note.id)}`, crypto.randomUUID()); } catch { /* Best effort marker. */ }
  for (const entry of capturedEntries) {
    if (entry.value?.baseRevision <= note.revision && sameContent(entry.value, note)) clearRecoveryEntry(storage, entry);
  }
}

import { NoteConflictError } from './local-notes.js';
import { sameContent } from './recovery-journal.mjs';

/** @param {{note: any, repository: any, journal: any, onChange?: (state: any) => void}} options */
export function createSaveCoordinator({ note, repository, journal, onChange = () => {} }) {
  let saved = structuredClone(note);
  let draft = { title: note.title, document: structuredClone(note.document) };
  let generation = 0;
  let running = null;
  let pending = null;
  let error = null;
  const dirty = () => !sameContent(draft, saved);
  const snapshot = () => ({ note: saved, draft, generation, dirty: dirty(), inFlight: Boolean(pending), error });
  const notify = () => onChange(snapshot());
  const persist = () => journal.write(draft, generation, saved.revision, pending);
  function edit(next) {
    if (sameContent(next, draft)) return;
    draft = structuredClone(next); generation += 1; error = null;
    if (dirty() || pending) persist(); else journal.clear();
    notify();
  }
  function flush() {
    if (running) return running;
    if (!dirty()) return Promise.resolve({ ok: true, note: saved });
    running = (async () => {
      // Bound each drain. New edits continue through the existing debounce, never an error retry loop.
      for (let writes = 0; writes < 10 && dirty(); writes += 1) {
        if (!journal.isCurrent()) { error = new NoteConflictError(); notify(); return { ok: false, error }; }
        const target = structuredClone(draft);
        pending = { ...target, generation, expectedRevision: saved.revision };
        persist(); error = null; notify();
        try {
          saved = await repository.save(saved.id, target, saved.revision);
          pending = null;
          if (dirty()) persist(); else journal.clear();
          notify();
        } catch (cause) {
          pending = null; error = cause; persist(); notify();
          return { ok: false, error: cause };
        }
      }
      return dirty() ? { ok: false, pending: true } : { ok: true, note: saved };
    })().finally(() => { running = null; });
    return running;
  }
  async function transition(lifecycle) {
    const result = await flush();
    if (!result.ok) return result;
    try {
      if (!journal.isCurrent()) throw new NoteConflictError();
      if (saved.lifecycle !== lifecycle) saved = await repository.setLifecycle(saved.id, lifecycle, saved.revision);
      notify(); return { ok: true, note: saved };
    } catch (cause) { error = cause; notify(); return { ok: false, error: cause }; }
  }
  return { edit, flush, transition, snapshot, clearJournal: () => journal.clear() };
}

'use client';

import Link from 'next/link';
import { useRouter } from 'next/navigation';
import { createContext, useCallback, useContext, useEffect, useMemo, useRef } from 'react';

type Guard = () => Promise<boolean>;
const NavigationContext = createContext<{ register: (guard: Guard) => () => void; navigate: (href: string) => Promise<void> } | null>(null);

export function NavigationGuardProvider({ children }: { children: React.ReactNode }) {
  const router = useRouter();
  const guard = useRef<Guard | null>(null);
  const register = useCallback((next: Guard) => { guard.current = next; return () => { if (guard.current === next) guard.current = null; }; }, []);
  const navigate = useCallback(async (href: string) => { if (!guard.current || await guard.current()) router.push(href); }, [router]);
  const value = useMemo(() => ({ register, navigate }), [register, navigate]);
  return <NavigationContext.Provider value={value}>{children}</NavigationContext.Provider>;
}

export function useNavigationGuard(guard: Guard) {
  const navigation = useContext(NavigationContext);
  useEffect(() => navigation?.register(guard), [navigation, guard]);
}

export function GuardedLink({ href, ...props }: Omit<React.ComponentProps<typeof Link>, 'href' | 'onNavigate'> & { href: string }) {
  const navigation = useContext(NavigationContext);
  return <Link {...props} href={href} onNavigate={(event) => { if (navigation) { event.preventDefault(); void navigation.navigate(href); } }} />;
}

function isRecord(value) {
  return value !== null && typeof value === 'object' && !Array.isArray(value);
}

function invalid(code, path, message) {
  return { status: 'invalid', editable: false, issues: [{ code, path, message }] };
}

function unsupported(code, path, message) {
  return { status: 'unsupported', editable: false, issues: [{ code, path, message }] };
}

function getUnknownKeys(value, allowed) {
  return Object.keys(value).filter((key) => !allowed.has(key));
}

function validateAttributes(rawAttrs, typeSpec, path) {
  if (rawAttrs !== undefined && !isRecord(rawAttrs)) {
    return invalid('invalid-attributes', path, 'Node attributes must be a JSON object.');
  }

  const allowed = typeSpec.attrs ?? {};
  const attrs = rawAttrs ?? {};
  const unknown = Object.keys(attrs).filter((key) => !Object.hasOwn(allowed, key));
  if (unknown.length) {
    return unsupported('unknown-attribute', path, `Unknown attribute(s): ${unknown.join(', ')}.`);
  }

  for (const [name, attribute] of Object.entries(allowed)) {
    if (!Object.hasOwn(attrs, name) && !Object.hasOwn(attribute, 'default')) {
      return invalid('missing-attribute', `${path}.attrs.${name}`, `Required attribute "${name}" is missing.`);
    }
  }

  return null;
}

function validateMark(mark, schema, path) {
  if (!isRecord(mark) || typeof mark.type !== 'string') {
    return invalid('invalid-mark', path, 'A mark must be an object with a string type.');
  }

  const unknownKeys = getUnknownKeys(mark, markKeys);
  if (unknownKeys.length) {
    return unsupported('unknown-field', path, `Unknown mark field(s): ${unknownKeys.join(', ')}.`);
  }

  const type = schema.marks[mark.type];
  if (!type) {
    return unsupported('unknown-mark', `${path}.type`, `Mark "${mark.type}" is not in schema v1.`);
  }

  const attributeIssue = validateAttributes(mark.attrs, type.spec, `${path}.attrs`);
  if (attributeIssue) return attributeIssue;

  if (mark.type === 'link') {
    for (const name of ['target', 'rel', 'class', 'title']) {
      const value = mark.attrs?.[name];
      if (value != null && typeof value !== 'string') {
        return invalid('invalid-link-attribute', `${path}.attrs.${name}`, `Link ${name} must be a string or null.`);
      }
    }
    const href = mark.attrs?.href;
    if (typeof href !== 'string' || href.length === 0) {
      return invalid('invalid-link', `${path}.attrs.href`, 'A link requires a non-empty href string.');
    }
    // Persist only navigation schemes that are meaningful to a note document.
    // This rejects javascript:, data:, and other executable/ambiguous protocols.
    if (!/^(https?:|mailto:|tel:)/i.test(href)) {
      return invalid('unsafe-link-protocol', `${path}.attrs.href`, 'Links must use http, https, mailto, or tel.');
    }
  }

  return null;
}

function validateNodeShape(node, schema, path) {
  if (!isRecord(node) || typeof node.type !== 'string') {
    return invalid('invalid-node', path, 'A node must be an object with a string type.');
  }

  const unknownKeys = getUnknownKeys(node, nodeKeys);
  if (unknownKeys.length) {
    return unsupported('unknown-field', path, `Unknown node field(s): ${unknownKeys.join(', ')}.`);
  }

  const type = schema.nodes[node.type];
  if (!type) {
    return unsupported('unknown-node', `${path}.type`, `Node "${node.type}" is not in schema v1.`);
  }

  if (node.type === 'text') {
    if (typeof node.text !== 'string' || node.text.length === 0 || node.content !== undefined || node.attrs !== undefined) {
      return invalid('invalid-text-node', path, 'Text nodes require non-empty text and cannot have attrs or content.');
    }
  } else if (node.text !== undefined) {
    return invalid('invalid-node-text', `${path}.text`, 'Only text nodes may contain a text field.');
  }

  const attributeIssue = validateAttributes(node.attrs, type.spec, `${path}.attrs`);
  if (attributeIssue) return attributeIssue;

  if (node.marks !== undefined) {
    if (!Array.isArray(node.marks)) {
      return invalid('invalid-marks', `${path}.marks`, 'Marks must be an array.');
    }
    for (let index = 0; index < node.marks.length; index += 1) {
      const markIssue = validateMark(node.marks[index], schema, `${path}.marks[${index}]`);
      if (markIssue) return markIssue;
    }
  }

  if (node.content !== undefined && !Array.isArray(node.content)) {
    return invalid('invalid-content', `${path}.content`, 'Node content must be an array.');
  }

  if (node.content) {
    for (let index = 0; index < node.content.length; index += 1) {
      const childIssue = validateNodeShape(node.content[index], schema, `${path}.content[${index}]`);
      if (childIssue) return childIssue;
    }
  }

  if (node.type === 'heading' && (!Number.isInteger(node.attrs?.level) || node.attrs.level < 1 || node.attrs.level > 6)) {
    return invalid('invalid-heading-level', `${path}.attrs.level`, 'Heading level must be an integer from 1 through 6.');
  }
  if (node.type === 'orderedList' && (!Number.isInteger(node.attrs?.start) || node.attrs.start < 1)) {
    return invalid('invalid-list-start', `${path}.attrs.start`, 'Ordered list start must be a positive integer.');
  }
  if (node.type === 'orderedList' && node.attrs?.type != null && typeof node.attrs.type !== 'string') {
    return invalid('invalid-list-type', `${path}.attrs.type`, 'Ordered list type must be a string or null.');
  }
  if (node.type === 'taskItem' && typeof node.attrs?.checked !== 'boolean') {
    return invalid('invalid-task-state', `${path}.attrs.checked`, 'Checklist items require a boolean checked value.');
  }
  if (node.type === 'attachmentReference') {
    if (typeof node.attrs?.attachmentId !== 'string' || node.attrs.attachmentId.length === 0) {
      return invalid('invalid-attachment-id', `${path}.attrs.attachmentId`, 'Attachment references require a non-empty attachmentId.');
    }
    if (typeof node.attrs?.label !== 'string') {
      return invalid('invalid-attachment-label', `${path}.attrs.label`, 'Attachment reference label must be a string.');
    }
  }
  if (node.type === 'codeBlock' && node.attrs?.language != null && typeof node.attrs.language !== 'string') {
    return invalid('invalid-code-language', `${path}.attrs.language`, 'Code language must be a string or null.');
  }

  return null;
}

function toProseMirrorDocument(canonical) {
  return { type: canonical.type, content: canonical.content };

export function validateCanonicalDocument(input, schema = getCanonicalSchema()) {
  try {
    if (!isRecord(input)) return invalid('invalid-wrapper', '$', 'Canonical document must be a JSON object.');

    if (!Number.isInteger(input.schemaVersion)) {
      return invalid('invalid-schema-version', '$.schemaVersion', 'schemaVersion must be an integer.');
    }
    if (input.schemaVersion > CANONICAL_SCHEMA_VERSION) {
      return unsupported('unsupported-schema-version', '$.schemaVersion', `Schema version ${input.schemaVersion} is newer than supported version ${CANONICAL_SCHEMA_VERSION}.`);
    }
    if (input.schemaVersion !== CANONICAL_SCHEMA_VERSION) {
      return invalid('invalid-schema-version', '$.schemaVersion', `Schema version must be ${CANONICAL_SCHEMA_VERSION}.`);
    }

    const unknownWrapperKeys = getUnknownKeys(input, wrapperKeys);
    if (unknownWrapperKeys.length) {
      return unsupported('unknown-field', '$', `Unknown document field(s): ${unknownWrapperKeys.join(', ')}.`);
    }
    if (input.type !== CANONICAL_DOCUMENT_TYPE) {
      return invalid('invalid-document-type', '$.type', 'Canonical schema v1 requires a ProseMirror doc root.');
    }
    if (!Array.isArray(input.content)) {
      return invalid('invalid-document-content', '$.content', 'Canonical document content must be an array.');
    }

    const wrapperIssue = validateNodeShape({ type: input.type, content: input.content }, schema, '$.document');
    if (wrapperIssue) return wrapperIssue;

    const prosemirrorNode = schema.nodeFromJSON(toProseMirrorDocument(input));
    prosemirrorNode.check();
    // ProseMirror uses null-prototype objects for attrs. Normalize to ordinary
    // JSON values so persistence/reload has a stable, portable representation.
    const normalizedNode = JSON.parse(JSON.stringify(prosemirrorNode.toJSON()));
    const document = {
      schemaVersion: CANONICAL_SCHEMA_VERSION,
      type: normalizedNode.type,
      ...(normalizedNode.attrs === undefined ? {} : { attrs: normalizedNode.attrs }),
      content: normalizedNode.content ?? [],
    };

    return { status: 'supported', editable: true, document, issues: [] };
  } catch (error) {
    return invalid('invalid-document-tree', '$', error instanceof Error ? error.message : 'ProseMirror rejected the document tree.');
  }
}

export function parseCanonicalDocument(jsonText, schema = getCanonicalSchema()) {
  if (typeof jsonText !== 'string') return invalid('invalid-json-input', '$', 'JSON input must be a string.');
  let value;
  try {
    value = JSON.parse(jsonText);
  } catch (error) {
    return invalid('malformed-json', '$', error instanceof Error ? error.message : 'JSON parsing failed.');
  }
  return validateCanonicalDocument(value, schema);
}

export function serializeCanonicalDocument(input, schema = getCanonicalSchema()) {
  const validation = validateCanonicalDocument(input, schema);
  if (validation.status !== 'supported') return { status: validation.status, json: null, validation };
  return { status: 'serialized', json: JSON.stringify(validation.document), document: validation.document };
}

export function canonicalDocumentFromTiptapJSON(editorJson, schema = getCanonicalSchema()) {
  if (!isRecord(editorJson)) return invalid('invalid-editor-json', '$', 'Tiptap editor JSON must be an object.');
  const candidate = { schemaVersion: CANONICAL_SCHEMA_VERSION, ...editorJson };
  return validateCanonicalDocument(candidate, schema);
}

export function toTiptapJSON(canonicalDocument, schema = getCanonicalSchema()) {
  const validation = validateCanonicalDocument(canonicalDocument, schema);
  if (validation.status !== 'supported') return { status: validation.status, json: null, validation };
  return { status: 'ready', json: toProseMirrorDocument(validation.document), document: validation.document };
}

function addWarning(warnings, code, path, message) {
  const key = `${code}:${path}`;
  if (!warnings.has(key)) warnings.set(key, { code, path, message });
}

function inlinePlainText(nodes = [], warnings, path) {
  return nodes.map((node, index) => {
    const nodePath = `${path}[${index}]`;
    if (node.type === 'text') {
      if (node.marks?.length) addWarning(warnings, 'inline-formatting-omitted', nodePath, 'Plain text projection omits inline mark formatting.');
      return node.text;
    }
    if (node.type === 'hardBreak') return '\n';
    if (node.type === 'attachmentReference') {
      addWarning(warnings, 'attachment-projection', nodePath, 'Plain text can show the label but cannot preserve an attachment reference.');
      return node.attrs.label || node.attrs.attachmentId;
    }
    return '';
  }).join('');
}

function blockPlainText(node, warnings, path) {
  switch (node.type) {
    case 'paragraph':
    case 'heading':
      if (node.type === 'heading') addWarning(warnings, 'block-formatting-omitted', path, 'Plain text projection omits heading level.');
      return inlinePlainText(node.content, warnings, `${path}.content`);
    case 'codeBlock':
      if (node.attrs?.language) addWarning(warnings, 'code-language-omitted', path, 'Plain text projection omits code block language metadata.');
      return inlinePlainText(node.content, warnings, `${path}.content`);
    case 'blockquote':
      addWarning(warnings, 'block-formatting-omitted', path, 'Plain text projection omits blockquote structure.');
      return (node.content ?? []).map((child, index) => blockPlainText(child, warnings, `${path}.content[${index}]`)).join('\n');
    case 'bulletList':
    case 'orderedList':
    case 'taskList': {
      addWarning(warnings, node.type === 'taskList' ? 'checklist-state-projected' : 'list-structure-omitted', path, 'Plain text projection does not preserve nested list structure.');
      return (node.content ?? []).map((item, index) => {
        const itemText = (item.content ?? []).map((child, childIndex) => blockPlainText(child, warnings, `${path}.content[${index}].content[${childIndex}]`)).join('\n');
        const prefix = item.type === 'taskItem' ? (item.attrs.checked ? '[x] ' : '[ ] ') : '- ';
        return `${prefix}${itemText}`;
      }).join('\n');
    }
    default:
      return '';
  }
}

export function canonicalToPlainText(input, schema = getCanonicalSchema()) {
  const validation = validateCanonicalDocument(input, schema);
  if (validation.status !== 'supported') return { status: 'blocked', text: null, warnings: [], validation };
  const warnings = new Map();
  const text = validation.document.content.map((node, index) => blockPlainText(node, warnings, `$.content[${index}]`)).join('\n');
  return { status: 'projected', text, warnings: [...warnings.values()] };
}

function escapeMarkdownText(text) {
  return text.replace(/[\\`*_{}\[\]<>!|]/g, '\\$&');
}

function renderInline(nodes = [], warnings, path) {
  return nodes.map((node, index) => {
    const nodePath = `${path}[${index}]`;
    if (node.type === 'hardBreak') return '  \n';
    if (node.type === 'attachmentReference') {
      addWarning(warnings, 'attachment-not-representable', nodePath, 'Markdown has no canonical attachment-reference type; a label is shown as text only.');
      return `[Attachment: ${escapeMarkdownText(node.attrs.label || node.attrs.attachmentId)}]`;
    }

    let text = escapeMarkdownText(node.text);
    for (const mark of node.marks ?? []) {
      switch (mark.type) {
        case 'bold': text = `**${text}**`; break;
        case 'italic': text = `*${text}*`; break;
        case 'strike': text = `~~${text}~~`; break;
        case 'link': {
          const href = String(mark.attrs.href).replace(/[<>\\\s]/g, (character) => encodeURIComponent(character));
          text = `[${text}](<${href}>)`;
          break;
        }
        default: break;
      }
    }
    return text;
  }).join('');
}

function codeFence(code) {
  const runs = code.match(/`+/g) ?? [];
  const longest = runs.reduce((max, run) => Math.max(max, run.length), 0);
  return '`'.repeat(Math.max(3, longest + 1));
}

function renderList(node, depth, warnings, path) {
  if (node.type === 'taskList') {
    addWarning(warnings, 'extended-markdown-checklist', path, 'Checklist output uses the common GFM [x]/[ ] extension, which is not part of basic CommonMark.');
  }
  if (node.type === 'orderedList' && node.attrs?.type != null) {
    addWarning(warnings, 'ordered-list-style-omitted', path, 'Markdown numeric list markers do not preserve the ordered list marker style.');
  }
  const output = [];
  const first = Number.isInteger(node.attrs?.start) ? node.attrs.start : 1;
  for (let index = 0; index < (node.content ?? []).length; index += 1) {
    const item = node.content[index];
    const indent = '  '.repeat(depth);
    const marker = item.type === 'taskItem' ? (item.attrs.checked ? '- [x]' : '- [ ]')
      : node.type === 'orderedList' ? `${first + index}.` : '-';
    const itemBlocks = item.content ?? [];
    const paragraph = itemBlocks.find((block) => block.type === 'paragraph');
    output.push(`${indent}${marker} ${paragraph ? renderInline(paragraph.content, warnings, `${path}.content[${index}].paragraph`) : ''}`.trimEnd());
    for (let childIndex = 0; childIndex < itemBlocks.length; childIndex += 1) {
      const child = itemBlocks[childIndex];
      if (child === paragraph) continue;
      const nested = renderBlock(child, depth + 1, warnings, `${path}.content[${index}].content[${childIndex}]`);
      output.push(...nested.split('\n'));
    }
  }
  return output.join('\n');
}

function renderBlock(node, depth, warnings, path) {
  switch (node.type) {
    case 'paragraph':
      return renderInline(node.content, warnings, `${path}.content`);
    case 'heading':
      return `${'#'.repeat(node.attrs.level)} ${renderInline(node.content, warnings, `${path}.content`)}`;
    case 'codeBlock': {
      const code = inlinePlainText(node.content, warnings, `${path}.content`);
      const fence = codeFence(code);
      const language = node.attrs?.language ?? '';
      return `${fence}${language}\n${code}${code.endsWith('\n') ? '' : '\n'}${fence}`;
    }
    case 'blockquote':
      return (node.content ?? []).map((child, index) => renderBlock(child, depth, warnings, `${path}.content[${index}]`)
        .split('\n').map((line) => `> ${line}`).join('\n')).join('\n');
    case 'bulletList':
    case 'orderedList':
    case 'taskList':
      return renderList(node, depth, warnings, path);
    default:
      return '';
  }
}

export function canonicalToMarkdown(input, schema = getCanonicalSchema()) {
  const validation = validateCanonicalDocument(input, schema);
  if (validation.status !== 'supported') return { status: 'blocked', markdown: null, warnings: [], validation };
  const warnings = new Map();
  const markdown = validation.document.content.map((node, index) => renderBlock(node, 0, warnings, `$.content[${index}]`)).join('\n\n');
  return { status: 'projected', markdown, warnings: [...warnings.values()] };
}

export function createTiptapEditor({ element, document, editable = true, onUpdate }) {
  const validation = validateCanonicalDocument(document);
  if (validation.status !== 'supported') {
    throw new TypeError(`Refusing to open unsupported document: ${validation.issues[0]?.message ?? validation.status}`);
  }

  const editorJson = toProseMirrorDocument(validation.document);
  return new Editor({
    element,
    extensions: createDocumentExtensions(),
    content: editorJson,
    editable,
    onUpdate: ({ editor }) => {
      const result = canonicalDocumentFromTiptapJSON(editor.getJSON());
      if (result.status === 'supported') onUpdate?.(result.document);
    },
  });
}

export const CANONICAL_SCHEMA_VERSION = 1;
export const CANONICAL_DOCUMENT_TYPE = 'doc';

export function createEmptyCanonicalDocument() {
  return { schemaVersion: CANONICAL_SCHEMA_VERSION, type: CANONICAL_DOCUMENT_TYPE, content: [] };
}

export function plainTextToCanonicalDocument(text) {
  if (typeof text !== 'string') {
    throw new TypeError('Plain text input must be a string.');
  }

  if (text.length === 0) return createEmptyCanonicalDocument();

  return {
    schemaVersion: CANONICAL_SCHEMA_VERSION,
    type: CANONICAL_DOCUMENT_TYPE,
    content: text.split('\n').map((line) => ({
      type: 'paragraph',
      ...(line.length === 0 ? {} : { content: [{ type: 'text', text: line }] }),
    })),
  };
}
